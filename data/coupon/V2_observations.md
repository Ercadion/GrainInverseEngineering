# V2 그레인 — 시편에서 넘어온 관찰 항목

시편으로 하던 T2·T3-b·T4 를 여기로 옮겼다. 추가 용융 0회.

⚠ **전제 두 개 위에 서 있다.** 아래 관찰이 어긋나면 **여기부터 의심한다.**

1. 실리콘 몰드 압축 성형의 압력이 **형상을 고정한다**
2. **탈형이 성공한다** — 실리콘 코어가 추진제에서 깨짐 없이 빠진다

---

## T2 — 추진제 생존 (`t_prop_min` 2.0 mm 의 시험)

얇은 추진제는 케이스 쪽이 아니라 **로브 사이 쐐기 끝**(포트 최소반경 근처)에
생긴다. 6-로브 깊음(amp 7.0)에서 4.6 mm² 가 2 mm 아래다.

| 관찰 | 기록 |
|---|---|
| 탈형 직후 쐐기 끝이 부서졌는가 | |
| 부서졌다면 몇 번째 로브, 어느 반경쯤 | |
| **미충전인가 파단인가** (⚠ 반드시 구분) | |
| 24 h 뒤 균열 | |
| 사진 (`V2_wedge_*.jpg`) | |

- 쐐기가 **살아남으면** → `t_prop_min` 2.0 mm 가 보수적이었다, 내릴 여지 있음
- **부서지면** → 2.0 mm 가 낙관적이었다, 올려야 함
- **미충전이면** → 재료가 아니라 **압력** 문제다. `t_prop_min` 을 올리지 말 것

## T3-b — 포트 전사 (δ 의 교차 확인)

| 재는 것 | 설계 | 실측 |
|---|---|---|
| 포트 최대 반경 | | |
| 포트 최소 반경 | | |
| 로브 꼭짓점 반경 (사진 + 원 피팅) | | |

δ(V2) = max \|실측 − 설계\|. 시편에서 계산한 **0.020 mm** 와 맞는지 본다.
크게 어긋나면 전제 ①(압력이 형상을 고정한다)이 틀린 것이다.

## T4 — 수축률·밀도비

| | 값 |
|---|---|
| 그레인 질량 [g] | |
| 외경·길이 [mm] | |
| 포트 실측 (위 T3-b) | |
| **추진제 수축률** = (코어 핀 실측 − 그레인 포트 실측) ÷ 코어 핀 실측 | |
| **밀도비** = (질량 ÷ 체적) ÷ 1.841 g/cm³ | |

⚠ **코어 핀 실측에서 뺀다** — 몰드가 아니라. 핀 기준이어야 실리콘 수축 0.2 % 가
빠진다. 체적은 실측 치수로 계산한다 (KNSB 는 수용성이라 물 치환법 불가).

목표 밀도비 0.92.
