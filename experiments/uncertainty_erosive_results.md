## ① 불확실성 예산

기준 설계: 외부 대조 형상(Ø50 · 코어 Ø20 · 30 mm × 3 · A_t 61.75 mm² · ε 8),
효율은 프로젝트 기본값(c\* 0.95, 노즐 0.95). 1σ 는 **전부 가정**이다.

| 파라미터 | 1σ [가정] | I | P_max | F_max | t_b |
|---|---|---|---|---|---|
| a (배율) | 10 % | +2.22 % | **+9.80 %** | **+11.78 %** | **−9.19 %** |
| n (가산) | 0.05 | +0.72 % | +4.99 % | +6.00 % | −3.65 % |
| 밀도비 | 1.5 % | +1.83 % | +1.48 % | +1.78 % | +0.11 % |
| c\* 효율 | 0.03 | **+3.86 %** | +3.10 % | +3.72 % | +0.29 % |
| 노즐 효율 | 0.03 | **+3.16 %** | 0 | +3.16 % | 0 |
| A_t | 1 % | −0.22 % | −0.98 % | −0.18 % | −0.11 % |
| 공표 c\* | 3 % | **+3.67 %** | +2.98 % | +3.58 % | +0.23 % |
| γ | 0.01 | −0.30 % | 0 | −0.41 % | 0 |
| separation_frac | 0.10 | +1.22 % | 0 | 0 | +0.34 % |

합성 1σ (독립 가정 제곱합)과 분산 기여 상위:

| 지표 | 합성 1σ | 상위 기여 |
|---|---|---|
| 총역적 I | 6.98 % | c\* 효율 31 % · 공표 c\* 28 % · 노즐 효율 20 % (a 는 10 %) |
| P_max | 11.94 % | a 67 % · n 17 % · c\* 효율 7 % |
| F_max | 14.65 % | a 65 % · n 17 % |
| 연소시간 | 9.90 % | a 86 % · n 14 % |

**읽는 법**

- **I 는 c\*·노즐이, 압력·곡선 모양·연소시간은 연소속도가 정한다.** 정보원이
  갈라져 있으므로 V2 에서 떼어 잴 수 있다 → ②.
- c\* 효율과 공표 c\* 는 I·P 에 거의 같은 꼴로 들어간다 → 실측에서는 **곱
  c\*·η 하나**로 재는 것이 맞다 (②의 1 단이 그렇게 한다).
- A_t 는 ±1 % 면적이면 작다. 삭마가 그보다 크면 따로 본다.
- `separation_frac` ±0.1 → I 1.22 % 는 기록 "0.3 vs 0.4 가 총역적 1 %p" 와
  **독립적으로 일치**한다.
- 외부 대조 잔차 −2.98 % 는 I 의 합성 1σ(약 7 %) 안이다. 예산만으로는 원인을
  하나로 지목할 수 없다 — 크기가 맞는 후보는 노즐 효율, c\* 규약, 박리 문턱.

**검증**

- 자동미분 vs 중앙차분 (I, 6 개 파라미터): 최대 차이 **0.005 %p**.
- 격자 n=121 과 n=241: 합성 1σ 가 I 6.98/6.98, P_max 11.94/11.93, t_b 9.90/9.90 — 격자 무관.

## ② V2 순서 적합 — c\* 먼저

    1 단  c*_meas = Ā_t·∫P dt / m_p     (Ā_t = 시험 전후 평균, m_p = 장전 질량 실측)
    2 단  η_Cf, separation_frac          (기존 v2_cf_fit.py — F/(P·A_t), c* 무관)
    3 단  1 단 값을 고정하고 정상창 P(t) 로 (a 배율, Δn) 최소제곱 + 공분산

자가검증 (참값 a×1.08 · Δn +0.03 · c\* 효율 0.90 · 삭마 2 % · 압력 잡음 1 % ·
측정은 n=161, 적합은 n=121 로 역범죄 회피):

| | c\* 효율 | a 배율 | Δn |
|---|---|---|---|
| 참값 | 0.900 | 1.080 | +0.030 |
| **순서 적합** | 0.8989 (−0.12 %) | 1.0819 (**+0.18 %**) | +0.0294 |
| 1 단 생략 (c\* 0.95 그대로) | — | 0.9063 (**−16.1 %**) | +0.146 (**+0.116**) |

**1 단을 건너뛰면 a 가 16 % 틀린 채로 잔차는 여전히 1.15 % 로 "잘 맞는다."**
이 a 를 V3 의 다른 형상에 쓰면 예측이 틀린다 — §6.4 의 경고가 실제 크기로 드러난 것이다.

⚠ 두 경우 모두 a·n 상관 −0.99 → "n 식별 불가" 경고가 떴다. σ_n 은 0.003 으로
작지만, 생략 쪽에서 Δn 이 σ 의 39 배 빗나갔다. **상관이 크면 작은 σ 를 믿으면 안
된다** (다른 오차를 n 이 흡수한다). 창 압력비 1.67 인 BATES 곡선이라 그렇다.

## ③ 침식연소 — 세그먼트별 국소 질량유속

### 발견: 설계 문서의 침식 하드 제약은 코드에 없다

§4.5 제약 표 "포트 면적 / 노즐목 면적 ≥ 기준값" 과 §10 리스크 대응
"포트/노즐목 면적비 하드 제약" 은 **`gre/` 어디에도 구현돼 있지 않다**
(`grep` 으로 확인). 지금까지의 설계는 이 가정을 검사받지 않았다.

### 진단 (`gre/validate/erosive.py`)

    G_k(w) = ρ_p·r(p)·Σ_{j≤k} A_b,j(w) / A_port,k(w)       (lengths[0] = 헤드엔드)

| 설계 | 최대 G [kg/m²s] | 최소 A_port/A_t | 포트 M | 헤드–노즐 Δp | P_eq 초기 |
|---|---|---|---|---|---|
| A 외부 대조 Ø50 BATES 30×3 | 650 | 5.09 | 0.124 | ≈1.7 % | 2.76 MPa |
| B Ø40 씨앗 0, 74×3 (V2 후보) | 668 | 5.02 | 0.126 | ≈1.8 % | 2.81 MPa |
| C 같은 형상, 74×4 | **898** | 5.02 | 0.126 | ≈1.8 % | 3.76 MPa |

- 세 설계 모두 최대 G 는 **점화 직후(w=0), 노즐 쪽 세그먼트**.
- **면적비는 M 만 정하고 G 는 정하지 못한다.** B → C 에서 면적비·M 은 그대로인데
  압력이 올라 G 가 34 % 커졌다 (G = p·A_t/(c\*·A_port) 이므로 G ∝ p).
  침식연소는 G 에 걸리므로 **면적비 제약만으로는 회피를 보장하지 않는다.**
- 현재 V2 후보(B)는 경고 출발점 1000 kg/m²s 아래지만 여유가 1.5 배뿐이다.

⚠ **문턱값은 미정이다.** `DEFAULT_LIMITS`(G 1000 · 면적비 2.0 · M 0.3) 는 "경고를
띄울 출발점" 이지 KNSB 에 대해 근거 있는 값이 아니다.

### 시험 (`tests/test_erosive.py`, 6 개 전부 통과)

- 노즐 쪽 G = 정상상태 질량 보존 `p·A_t/(c*·A_port)` (1.5 % 안 — 차이는 ρ_g 충전 항)
- 동일 포트 적층에서 G 비 1:2:3
- 평형압 음함수 경사 = 중앙차분 (상대 1e-4)
- 형상 경사는 `phi` 의 straight-through 편향을 **그대로** 물려받음 (비 1.3~1.9,
  gradient_audit §2 의 1.4~1.8 과 일치) — 이 모듈이 새 편향을 만들지 않음
- 벌점 `erosive_hinge` 활성·유한 경사

⚠ 시험 중 잡은 결함: 초판은 평형압을 no_grad 이분법 결과로 써서 **압력 경로의
경사가 통째로 빠져 있었다.** 음함수 정리(뉴턴 한 걸음)로 고쳤다.
